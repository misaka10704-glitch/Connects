Version 1.7 · iPad / iOS 12+

Connects

旧平板上的正经 AI 阅读壳。

为仍在服役的 iPad Air 1 而写：自带 Key、流式对话、原生数学与 Markdown，会话随时带走。

打开仓库 了解能力

动机

主流客户端默认新设备。旧硬件被落在后面。

屏幕与续航仍适合长时间推导，却很难找到能稳定装上、又能自管 Key 的双模型聊天应用。Connects 把兼容性放在第一位。

  1. 兼容优先 UIKit + iOS 12，不为 SwiftUI / 最新 API 牺牲旧机。
  2. 自己带 Key DeepSeek / Kimi 等存在本机钥匙串，不经第三方中转。
  3. 为阅读排版 居中阅读列、可调字号、思考可折叠，数学尽量渲染完整。

能力

1.7 起，已完成回复走原生渲染主路径。

流式仍轻量更新；定稿后由 Native Markdown + iosMath 绘制，减少旧机 WebKit 闪烁与截断。

01

原生 Markdown / TeX

解析块级结构与行内公式，内置 iosMath 0.9.x 与 XITS 字体；兼容 \( \)、$$ $$、\boxed 以及常见算子归一化。

02

稳定流式

SSE 按固定节奏刷新界面；UTF-8 分包与缓冲不再互相踩踏。思考过程直播展开，结束后默认折叠，避免切入会话时留下大片空白。

03

多会话工作台

新建、搜索、归档、重命名、分叉；助手消息可复制 / 重跑 / 换版本；完整 Markdown 导出与分享。

04

侧拉与窄栏

iPad Slide Over / 分屏时按宽度重排；公式按可用宽度缩放，参考来源折叠为可点击标题列表。

05

联网检索（可选）

开启后由 App 代搜并注入上下文；回答末尾以紧凑「参考来源」呈现，避免裸 URL 搅乱版面。

模型

多提供商，本机配置。

在设置里填写各家 Key。费用与配额由你的账号承担。

DeepSeek

V4 Flash / Pro。偏快推理与长文推导。

Kimi

K3 旗舰（`kimi-k3`）与 K2.6，支持图片；可切国内 / 海外节点。

更多

可见模型池可扩展（如 Qwen、GLM、豆包等，视本机构建配置）。

技术

刻意保守的技术栈。

UI
UIKit · 无 SwiftUI / Combine · 目标 iPad（TARGETED_DEVICE_FAMILY = 2）
网络
URLSession SSE · 多会话并行生成，切换聊天不打断后台流
渲染
NativeMarkdownParser + NativeMessageLayouter + iosMath；流式阶段仍用轻量纯文本
数据
会话本地持久化 · Keychain 存 Key · Markdown 可导出带走

开始

用 Xcode 打开即可跑。

  1. 克隆仓库，打开 Connects.xcodeproj。
  2. Signing 选择你的 Team，目标选真机 iPad 或 iOS 12+ 模拟器。
  3. 首次真机安装后，在「设置 → 通用 → 设备管理」信任开发者证书。
  4. 侧栏设置里填入 API Key，开始对话。
