How it works

聊天、阅读、改文件，同一个壳。

不经云端中转、不绑生态。Key 在本机，文件在本机，Agent 干活的每一步都留痕可撤。

1

自带 Key（BYOK）

DeepSeek / Kimi / Qwen / GLM / 豆包 / MiniMax / StepFun / 混元 / Yi / SiliconFlow 内置目录；自定义提供商填个 Base URL 就行（base / /v1 / 完整端点都认）。Key 只进 Keychain。

2

原生渲染管线

NativeMarkdownParser → NativeMessageLayouter 每条消息出一张 bitmap，滚动 = 纹理合成。iosMath / KaTeX 成图，宽公式横向滚动带；流式阶段轻量纯文本，完成即出片。

3

Study 工作区 Agent

Ask / Plan / Agent 三模式。对整个文件夹跑 list_dir / read_file / grep / glob；propose_edit / create_file / delete_file 全部进 Diff 审查，Keep 才落盘。

Details

为阅读与改造做的那些细节。

Workspace agent

一个工作区，三种模式。

工具调用走 <<<CONNECTS_TOOL>>> 协议，读工具放开整个文件夹，写工具一律先进审查会话——Agent 提的不是"已改"，是"提案"。

Ask

只读工具 + ask_user。读文档、答问题、给建议，一个字节都不动。

Plan

可产计划文档与拆解，但不允许 propose_edit / delete_file——先想清楚再动手。

Agent

全工具集：跨文件改、建、删 + spawn_subagent 分工；所有改动进逐文件 Diff，Keep / Undo 由你裁决。

agent tools — workspace scoped 
# Ask / Plan / Agent — 工具集不变，权限变
name: list_dir | read_file | grep | glob | ask_user | update_plan
        propose_edit | create_file | delete_file | spawn_subagent

# 写操作 → WorkspaceEditSession → 逐文件 Keep / Undo
WRITE SCOPE: workspace 内任意相对路径（含子目录），越界直接拒绝

Get started

源码或 IPA，两条路都能跑。

  1. 源码：克隆仓库，打开 Connects.xcodeproj，Signing 换成你的 Team，选 Connects-iPad / Connects-iPhone scheme 直接跑。
  2. IPA：Releases 下未签名 Connects.ipa，用 Sideloadly / AltStore / SideStore 自签安装；真机首次启动后在「设置 → 通用 → 设备管理」信任证书。
  3. 配 Key：侧栏设置里填任意提供商 Key——或加一个自定义 OpenAI 兼容端点。
  4. 进 Study：打开一个文件夹作为工作区，切 Agent 模式，让它读、让它改——每个文件你都有最终裁决权。
